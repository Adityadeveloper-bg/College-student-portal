# 🎓 EduSphere – Smart Campus Student Portal

EduSphere is a student campus portal designed to bring important academic
and campus activities together in one platform.

## 🚀 Live Demo

[Visit EduSphere](https://adityadeveloper-bg.github.io/College-student-portal/)

## ✨ Features

- 📊 Student Dashboard
- 📚 Learning Resources
- 📝 Notes
- 💡 Student Projects
- 🏆 Hackathons
- 💼 Placements
- 👨‍🏫 Faculty Information
- 📅 Campus Events
- 🎯 Career Guidance

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## 📸 Project Preview

The project provides a modern student-focused campus interface
with navigation for academics, projects, placements and career resources.

## 🔮 Future Improvements

- Student login/signup
- Individual student profiles
- Attendance tracking
- Certification management
- Admin dashboard
- Database integration
- Backend/API integration
